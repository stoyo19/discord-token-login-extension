# 🔑 Discord Token Manger Extension

A lightweight Chrome/Chromium extension that allows you to copy your active Discord token with a single click and log into any Discord account using a token.

## ✨ Features

* ** Get Current Token:** Quickly copy your active Discord account token directly to your clipboard without opening DevTools.
* **🔑 Fast Token Login:** Log into any Discord account instantly using a valid token directly from the popup.
* **⚡ Simple & Lightweight:** Minimalistic interface with zero extra bloat.

## 🛠️ Installation Guide (Load Unpacked Extension)

Since this extension is developer-focused, you can easily load it into Chrome or any Chromium-based browser (Brave, Edge, Opera) as an unpacked extension.

### Step-by-Step Instructions:

1. **Clone or Download the Repository**
   * Click the green **Code** button at the top of this repository and select **Download ZIP** (or run ` git clone https://github.com/stoyo19/discord-token-login-extension `).
   * Extract the ZIP file to a folder on your computer.

2. **Open Extensions Page in Chrome(opera, brave, edge also work)**
   * Open your browser and navigate to `chrome://extensions/` in your address bar.
   * Alternatively, click the **Three Dots Menu** (top right) ➔ **Extensions** ➔ **Manage Extensions**.

3. **Enable Developer Mode**
   * Toggle the **Developer Mode** switch located at the top right corner of the Extensions page.

4. **Load the Extension**
   * Click the **Load unpacked** button in the top-left menu bar.
   * Select the extracted folder containing the `manifest.json` file.

**After completing steps 1-4 you should have something similar to this**

5. **Pin the Extension**
   * Click the puzzle piece icon (Extensions) in your browser toolbar and pin **Discord Token Manager** for easy access.

## 🚀 How to Use

1. **Navigate to Discord:** Go to [discord.com/app](https://discord.com/app).
2. **Open Extension:** Click on the extension icon in your browser toolbar.
3. **Get Current Token:** Click **"Get Token"** to instantly display or copy your active token.
4. **Login via Token:** Paste a valid token into the input field and click **"Login"**. The page will refresh and log you into the corresponding account.

---

## ⚠️ Security & Privacy Notice

* **Protect Your Token:** Your Discord token grants full access to your account. **Never share your token with anyone.**
* **Local Processing:** This extension operates entirely locally inside your browser. It does not collect, store, or transmit your tokens to any external server.
